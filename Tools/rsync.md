# دستور پشتیبان‌گیری کامل از سرور ریموت

```bash
rsync -avz --partial --progress USER@HOST_OR_IP:/etc/ ./etc_backup_full/ && rsync -avz --partial --progress USER@HOST_OR_IP:/var/ ./var_backup_full/ && rsync -avz --partial --progress USER@HOST_OR_IP:/home/ ./home_backup_full/ && rsync -avz --partial --progress USER@HOST_OR_IP:/root/ ./root_backup_full/ && rsync -avz --partial --progress USER@HOST_OR_IP:/opt/ ./opt_backup_full/ && rsync -avz --partial --progress USER@HOST_OR_IP:/usr/local/ ./usr_local_backup_full/
```
---

## بررسی عملکرد این دستور

این دستور یک اسکریپت خط فرمان ترکیبی است که با استفاده از ابزار قدرتمند rsync، از مهم‌ترین بخش‌های یک سرور لینوکسی به صورت کامل نسخه پشتیبان (Backup) تهیه کرده و آن‌ها را روی سیستم محلی شما ذخیره می‌کند.

### نحوه کارکرد کلی:
- دستورات با استفاده از && به هم متصل شده‌اند؛ یعنی هر بخش به نوبت اجرا می‌شود و اگر بخش قبلی با موفقیت به پایان برسد، بخش بعدی شروع خواهد شد.
- بخش root@YOUR_SERVER_IP مشخص‌کننده نام کاربری و آدرس سرور مبدأ است.

## بخش‌های در حال پشتیبان‌گیری

1. پوشه /etc/ (./etc_backup_full/)
    - شامل تمامی تنظیمات اصلی سیستم‌عامل، شبکه، سرویس‌ها و برنامه‌های نصب‌شده.
2. پوشه /var/ (./var_backup_full/)
    - شامل لاگ‌ها، پایگاه‌های داده، وب‌سایت‌ها و فایل‌های متغیر سیستم.
3. پوشه /home/ (./home_backup_full/)
    - شامل فایل‌ها و پوشه‌های شخصی کاربران سرور.
4. پوشه /root/ (./root_backup_full/)
    - شامل فایل‌ها و تنظیمات اختصاصی کاربر ریشه (کاربر ارشد سیستم).
5. پوشه /opt/ (./opt_backup_full/)
    - شامل نرم‌افزارها و پکیج‌های اضافی و جانبی نصب‌شده روی سیستم.
6. پوشه /usr/local/ (./usr_local_backup_full/)
    - شامل نرم‌افزارها و اسکریپت‌های دستی که توسط مدیر سیستم نصب شده‌اند.

## بررسی سوییچ‌های استفاده‌شده در دستور

- پارامتر -a (--archive):
    - حالت آرشیو؛ تمامی دسترسی‌ها، مالکیت‌ها، تاریخ‌ها و ساختار فایل‌ها را به صورت کامل و دست‌نخورده حفظ می‌کند.
- پارامتر -v (--verbose):
    - خروجی مشروح؛ جزئیات فایل‌های در حال انتقال را در ترمینال نمایش می‌دهد.
- پارامتر -z (--compress):
    - فشرده‌سازی داده‌ها در حین انتقال از طریق شبکه برای افزایش سرعت.
- پارامتر --partial:
    - امکان ادامه دانلود یا کپی فایل‌های نیمه‌کاره در صورت قطع ناگهانی ارتباط اینترنت یا شبکه.
- پارامتر --progress:
    - نمایش درصد پیشرفت، حجم انتقال‌یافته و سرعت دانلود فایل‌ها به صورت لحظه‌ای.
